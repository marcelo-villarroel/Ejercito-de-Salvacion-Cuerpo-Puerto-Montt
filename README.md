# Liga de Misericordia — Ejército de Salvación (Puerto Montt)

Sitio de una sola página (landing) hecho en HTML + CSS + JavaScript puro (sin frameworks).

## Estructura

```
liga-misericordia/
├─ index.html
├─ css/
│  └─ styles.css
├─ js/
│  └─ script.js
└─ img/
   ├─ logo-escudo.png   ← escudo oficial (favicon + nav + footer)
   ├─ logo-mac.png       ← sello del ministerio (hero)
   ├─ hero.jpg           ← ⚠️ el archivo subido está vacío (0 KB), agrega una foto real
   └─ actividad-1.jpg … actividad-8.jpg  ← tus 8 fotos reales ✅
```

## Cómo verlo

1. Abre la carpeta en VS Code (`code .`).
2. Clic derecho sobre `index.html` → "Open with Live Server".
